# Oltivra — Google Stitch Package Order

## How to use

1. First give Stitch `oltivra_stitch_00_design_foundation.md` and wait for its acknowledgement.
2. Give **only one** package below at a time.
3. Share Stitch’s output here for review.
4. Move to the next package only after the current output is approved.

Each package has exactly six screens and repeats its scope boundaries so Stitch does not add, remove, or reinterpret product features.

| Order | File | Screens |
|---:|---|---|
| 00 | `oltivra_stitch_00_design_foundation.md` | Permanent visual system and staged-work rules; creates no screens |
| 01 | `oltivra_stitch_p01_onboarding.md` | Launch, age gate, legal consent, sign-in, username, avatar |
| 02 | `oltivra_stitch_p02_home_play_matchmaking.md` | Guide, Home, Play, Quick queue/ready, Survival ready |
| 03 | `oltivra_stitch_p03_quick_battle.md` | Quick Battle live states, Sudden Death, result |
| 04 | `oltivra_stitch_p04_survival.md` | Survival live states, elimination, spectator, result |
| 05 | `oltivra_stitch_p05_social_challenges.md` | Friends, search, profile, requests, challenges |
| 06 | `oltivra_stitch_p06_progress_profile.md` | Rankings, league, missions, profile, categories, cosmetics |
| 07 | `oltivra_stitch_p07_settings_safety.md` | Settings, profile editing, language, blocks, reports, deletion |
| 08 | `oltivra_stitch_p08_monetization_reliability.md` | Ad/privacy, rewarded XP, remove ads, recovery states |

## Fixed execution rule

After each package, Stitch must stop. It must not produce the next package, additional screens, alternate flows, or unrequested features. The next package is provided only after review.
