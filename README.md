# Oltivra — Live Trivia Battles

*Think fast. Rise higher.*

Monorepo for the Oltivra live multiplayer trivia game.

| Path | What |
|---|---|
| `backend/` | FastAPI authoritative game server (Cloud Run target) |
| `mobile/` | Flutter client |
| `admin/` | Next.js internal admin |
| `firebase/` | Firestore / RTDB / Storage rules, emulator image, rules tests |
| `infra/` | Cloud Build / Run / Armor / Tasks definitions |
| `loadtest/` | Locust load scenarios |
| `docs/` | Product spec, Stitch designs, implementation design & plan |

See `docs/superpowers/specs/2026-09-27-oltivra-design.md` for architecture.
